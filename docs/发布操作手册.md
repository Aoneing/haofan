2. 登录：右上角头像 → 扫码登录（**要用该小程序的管理员或开发者微信**）

   - 点「+」→「导入项目」
   - 目录选 **`C:\001_Simon\012_workbuddy\haofan`**（根目录，不要选到 `miniprogram` 子目录）
   - AppID 选「使用测试号」旁边下拉，或直接填 `wx9706ad7833033c64`

### 2. ⚠️ 部署云函数（最容易漏的一步，漏了线上必报错）

项目有 **4 个云函数**，上传小程序代码**不会**自动带上它们，必须逐个部署：

| 云函数 | 作用 |
|--------|------|

操作：在 IDE 左侧文件树展开 `cloudfunctions/`，**逐个右键每个云函数目录** → 选
**「上传并部署：云端安装依赖（不上传 node_modules）」**

## 二、方式 B：命令行自动上传（一劳永逸，但要先开一个开关）

我试过用官方 CLI 直接上传，被这个错误挡住：

```
[error] 工具的服务端口已关闭。要使用命令行调用工具，请手动打开
        工具 -> 设置 -> 安全设置，将服务端口打开。
```

微信把这个开关设计成**必须人工在界面上确认**（我这边是非交互终端，敲不了那个 `y`）。

**开启方法**：打开微信开发者工具 → 顶部菜单 **设置 → 安全设置 → 安全 → 服务端口 → 选择「打开」**

开启后告诉我一声，我就能直接跑这条命令帮你上传：

```bash
"C:\Program Files (x86)\Tencent\微信web开发者工具\cli.bat" upload ^
  --project "C:\001_Simon\012_workbuddy\haofan" ^
  -v 1.0.0 ^
  -d "餐次改为点开看交互，一周页周导航常驻吸顶并瘦身"
```

> 注意：云函数仍需按方式 A 第 2 步手动部署一次（CLI 上传不含云函数）。

## 三、上传之后：提交审核 + 发布（只能在网页后台做）

1. 打开 <https://mp.weixin.qq.com>，用小程序管理员微信扫码登录
2. **管理 → 版本管理** → 在「开发版本」里找到刚上传的 `1.0.0` → 点「**提交审核**」
3. 按提示填写：
   - 测试账号（如果涉及登录）
   - 功能页面路径、类目
   - 补充说明
4. 等审核（通常 1–2 个工作日，简单的小程序可能几小时）
5. 审核通过后 → 回到「版本管理」→ 点「**发布**」，正式上线

## 六、常见问题

**Q：上传后小程序打开是空的？**
A：云函数没部署，或还没导入 Excel。先查云函数部署状态，再走导入流程。

**Q：云函数调用报 `-501000` / 环境不存在？**
A：检查 `miniprogram/config.js` 的 `cloudEnv` 是否为 `cloud1-d1g8yreir12ed382c`，且云环境已开通。

**Q：改了代码想重新上传？**
A：版本号必须比上一次大，微信不允许同版本号重复上传。
