# 好饭 · 部署手册

> 目标：用**最低成本**把「好饭」跑在手机上，家人扫个码就能看今天吃什么。

---

## 0. 先看结论：三条路径对比

| 路径 | 费用 | 手机能访问 | 谁能用 | 需要审核/备案 |
| --- | --- | --- | --- | --- |
| 开发者工具模拟器 | 0 元 | ✗（只在电脑） | 只有你 | 不需要 |
| 预览二维码 | 0 元 | ✓ | 只有你（开发者本人） | 不需要 |
| **体验版（推荐）** | **0 元** | ✓ | **你 + 家人**（≤100 人） | 不需要 |
| 正式发布 | ≈239 元/年 | ✓ | 所有微信用户可搜到 | 需 ICP 备案 + 审核 |

**家庭自用请直接走「体验版」**：0 元、不用审核、不用备案、不会被陌生人搜到。

## 1. 为什么是 0 元（成本依据）

| 成本项 | 金额 | 依据 |
| --- | --- | --- |
| 小程序账号注册 | 0 元 | 个人主体注册免费，无需营业执照 |
| 微信认证费 | **0 元** | 腾讯云官方文档：*「非个人类型小程序没有通过微信认证不能开通云服务，**个人小程序暂无微信认证限制**」* —— 个人主体开云开发不需要那 300 元/年 |
| 云开发环境 | **0 元** | 2025-02-19 起，未创建过云环境的小程序账号可创建 1 个**免费体验环境**，**未发布上线期间无需续费** |
| 域名 / HTTPS / 服务器 | 0 元 | 云开发免域名、免备案、免运维（不用自建后端） |
| 代码上传 / 审核 | 0 元 | 体验版不走审核，微信不收费 |

> ⚠️ **两个必须知道的前提**
> 1. 免费体验环境在**小程序正式发布上线后**会转为付费环境（下一续费周期生效）。走体验版就一直是 0 元。
> 2. 该免费体验活动**截止 2026-12-31**，之后政策可能调整（官方承诺提前 3 个月通知）。真到那天，基础套餐 19.9 元/月。

## 2. 第 1 步：注册小程序，拿到 AppID

**耗时约 10 分钟 · 0 元**

1. 打开 <https://mp.weixin.qq.com/> → 右上角「**立即注册**」→ 选择「**小程序**」
2. 填写邮箱、密码 → 去邮箱点激活链接
   - ⚠️ 该邮箱**不能是**已注册过公众号 / 小程序的邮箱，换一个干净的
3. 主体类型选「**个人**」→ 填身份证姓名 + 号码 → 用**本人微信**扫码完成人脸实名
4. 注册完成后，去「**设置 → 基本设置**」填写小程序名称、头像、简介
   - ⚠️ 名称想好再填：个人主体一年只能改 2 次。名称被占用就加个后缀（如「好饭食谱」）
5. 去「**开发 → 开发管理 → 开发设置**」，复制页面上的 **AppID**（`wx` 开头的 18 位字符串）
   - 同页面的「小程序代码上传密钥」暂时用不上，保持关闭

> **为什么个人主体够用？** 本项目只用「云开发 + 从聊天记录选文件」，不涉及微信支付、手机号、位置、直播等需要资质的能力。

## 3. 第 2 步：安装微信开发者工具

**耗时约 5 分钟 · 0 元**

1. 下载稳定版：<https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html>
   - Windows 选「**Windows 64**」，下载后一路「下一步」
2. 首次打开，用**注册小程序时那个管理员微信**扫码登录
   - ⚠️ 必须用管理员/开发者身份登录，否则后面「云开发」按钮会灰掉

---

## 4. 第 3 步：导入项目

**耗时约 2 分钟**

1. 工具首页点「**+**」→ 选「**导入项目**」
2. 填写：

   | 字段 | 值 |
   | --- | --- |
   | 目录 | `D:\12_workbuddy\haofan` |
   | AppID | 粘贴第 1 步拿到的 AppID |
   | 后端服务 | 选「**微信云开发**」 |

3. 点「导入」
4. 工具若提示「AppID 与 project.config.json 不一致，是否同步」，选「**是**」
   - 或者手动把 `project.config.json` 里的 `"appid": "touristappid"` 改成你的 AppID

> **改完可以自查**：在项目根目录执行 `npm run preflight`，应当显示「阻断 0 项」。

---

## 5. 第 4 步：开通云开发 + 创建免费环境

**耗时约 3 分钟**

1. 工具顶部工具栏点「**云开发**」按钮
   - 若按钮灰显：确认登录微信是该小程序管理员，退出重登
2. 首次使用会弹出开通引导 → 同意条款 → 开通
3. 创建环境：

   | 字段 | 建议值 |
   | --- | --- |
   | 环境名称 | 纯英文小写，如 `haofan-prod`（**不能有中文**） |
   | 地域 | 上海（国内访问最快） |
   | 套餐 | 有选项就选「**免费体验**」 |

4. 创建完成后，在云开发控制台左上角能看到「**环境 ID**」，形如 `haofan-prod-1g2a3b4c5d`

> **本项目通常不需要把环境 ID 填进代码。**
> 只创建了一个环境时，`miniprogram/config.js` 保持 `cloudEnv: ''` 就会自动使用「默认环境」。
> 如果你建了**多个**环境（测试 + 生产），才需要打开 `miniprogram/config.js` 填上要用的那个。

---

## 6. 第 5 步：创建 3 个数据库集合

**耗时约 2 分钟**

云开发控制台 →「**数据库**」→ 点「**+**」新建集合，依次创建：

| 集合名 | 权限 | 说明 |
| --- | --- | --- |
| `periods` | 仅创建者可读写（默认即可） | 每期食谱的元信息 |
| `days` | 仅创建者可读写（默认即可） | 一天一条菜单 |
| `dishImages` | 仅创建者可读写（默认即可） | 菜名 → 配图 |

**两个要点：**

- ⚠️ 集合名**必须一字不差**（区分大小写）。写错会报 `collection not found`。
- 「仅创建者可读写」完全够用，**不会导致家人看不到数据**：这三个集合只由云函数读写，云函数走管理员权限不受集合权限限制；且本项目的数据查询**不按 openid 过滤**，全家共用同一份食谱（已核验代码）。

---

## 7. 第 6 步：上传部署 4 个云函数

**耗时约 5 分钟**

在开发者工具左侧资源管理器中，展开 `cloudfunctions`，对下面**每一个**目录做同样操作：

`menuParse`、`menuSave`、`menuQuery`、`dishImage`

> 右键 → 「**上传并部署：云端安装依赖（不上传 node_modules）**」

- 等待右下角提示「上传成功」（第一次约 30–60 秒，`menuParse` 要装 `xlsx` 会慢一点）
- 四个都完成后，目录名旁会出现云朵图标

> ⚠️ **不要选**「上传并部署：所有文件」——那会把本地 `node_modules` 一起打包上传，又慢又容易失败。

## 8. 第 7 步：模拟器验证

**耗时约 1 分钟**

- 左侧模拟器应显示「好饭」首页，底部三个 tab（今日 / 一周 / 我的），图标正常
- 首次进入是「**期后**」空态（还没导入数据），点「导入食谱」能跳到选择文件页
- 走到这一步，说明云环境 ✓ 云函数 ✓ 数据库 ✓ 全部打通

> 模拟器里「从聊天记录选择文件」可能选不到真实文件，这是正常的 —— 真机才能完整走通。

## 9. 第 8 步：手机上访问 ★

**先做这一步准备工作（重要）**

在微信里找到「**文件传输助手**」，把食谱 Excel（如 `food.xlsx`）发给它并保留在聊天记录里。

> 小程序只能从**聊天记录**里选文件，这是微信平台限制，不是 bug。

### 方式 A：预览二维码（最快，30 秒）

1. 工具顶部点「**预览**」→ 生成二维码
2. 用你自己的微信扫码 → 手机上立刻打开

> 适合自己先试。缺点是二维码有时效，且只有开发者本人能扫。

### 方式 B：体验版（推荐，家人也能用，长期有效）

1. 工具顶部点「**上传**」→ 填版本号（如 `0.1.0`）和备注（如 `首次上传`）→ 确定
2. 浏览器打开 <https://mp.weixin.qq.com/> 并登录 → 「**管理 → 版本管理**」
3. 在「**开发版本**」区域找到刚上传的版本 → 点「**选为体验版**」
4. 点「**体验版二维码**」→ 生成二维码
5. 添加家人：「**成员管理 → 体验成员 → 添加**」→ 输入家人微信号或手机号
   - 家人需要先关注「微信公众平台」安全助手？不需要，添加后直接扫码即可
6. 把体验版二维码发到家庭群 → 家人扫码 → 手机上就能用了

> 体验成员上限 100 人，家庭自用绰绰有余。
> 体验版不会被搜索到，也不需要审核和备案 —— 对「家里自己用」反而更私密合适。
> 每次改完代码重新「上传」后，需回后台**重新选为体验版**，家人才能看到新版本。

## 10. 第 9 步：导入第一份食谱

1. 手机打开「好饭」→ 首页空态点「**导入食谱**」（或从「我的」页进入）
2. 选「**从聊天记录选择**」→ 选中发给文件传输助手的 Excel
3. 等待解析 → 进入**校对页**：
   - 检查周期日期、每天菜名是否正确
   - 看告警码（如 `W006` 超长菜名、`W007`/`W009` 等），有「待校对」标记的重点看一眼
   - 年份判断错的话，用页面上的年份切换器重算星期
4. 确认无误 → 点「保存」
5. 回首页：今天（高亮）+ 明天（虚线预览）就出来了

## 11. 常见问题排查

| 现象 | 原因 | 解决 |
| --- | --- | --- |
| 「云开发」按钮灰显 | 登录的微信不是小程序管理员 | 退出登录，用管理员微信重新扫码 |
| `FunctionName not found` / `-501000` | 云函数没上传或没部署成功 | 重新右键「上传并部署：云端安装依赖」 |
| `collection not found` | 集合没建 / 名字拼错 | 云开发控制台核对 `periods` `days` `dishImages` |
| `env not found` / 云初始化失败 | 有多个环境但没指定 | 在 `miniprogram/config.js` 填 `cloudEnv` |
| tabBar 图标不显示 | 上传时忽略了未引用文件 | 工具「详情 → 本地设置」检查，或重新上传 |
| 手机扫码提示「该小程序未上线」 | 扫的是开发版二维码 | 用「预览」（本人），或先设为「体验版」 |
| 导入时选不到文件 | 小程序只能读聊天记录里的文件 | 先把 xlsx 发给「文件传输助手」 |
| 菜品没有配图 | 未接入生图接口 | 正常现象，显示文字占位；配图可选配 |
| 上传云函数长时间卡住 | 网络问题 / 依赖安装超时 | 重试；确认选的是「云端安装依赖」而非全部文件 |
| 家人扫码提示无权限 | 未加为体验成员 | 后台「成员管理 → 体验成员」添加后重扫 |

**仍然卡住时，先跑一次自检：**

```bash
cd D:\12_workbuddy\haofan
npm run preflight
```

它会检查 AppID、云环境、页面完整性、云函数依赖、tabBar 图标、全量 JS 语法，并给出针对性修复建议。

## 12. 想正式发布？（可选，要花钱 + 备案）

只有「所有微信用户都能搜到」时才需要，家庭自用完全不必：

1. **小程序备案（ICP）**：微信公众平台「设置 → 基本设置 → 小程序备案」，**免费**，审核约 1–20 个工作日
   - 2023 年 9 月起，未完成备案的小程序**无法发布上线**
2. **云开发转付费**：发布后免费环境转为付费环境（下一续费周期生效）
   - 基础套餐 19.9 元/月：2GB 容量、20 万次调用/月、2GB 外网出流量
3. **年度成本** ≈ 239 元（云开发）+ 0 元（备案）+ 0 元（个人主体无认证费）

## 13. 数据安全与备份

- 食谱数据存在**云开发数据库**，导入的 Excel 原文件存在**云存储**
- **备份策略**：留好每次导入的 Excel 原文件即可全量重建，不必单独备份数据库
- 若免费环境长期闲置被回收，用 Excel 重新导入即可完整恢复

## 14. 更新代码后怎么让家人看到

代码改动后需要走一遍「上传 → 设为体验版」：

```bash
npm run preflight   # 先自检
npm test            # 确保 20/20 通过
```

然后在开发者工具点「上传」→ 后台重新「选为体验版」→ 家人重新扫码（或在「最近使用的小程序」下拉刷新）。
