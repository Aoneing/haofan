## 一、上传代码（约 1 分钟）

1. 打开**微信开发者工具**，确认登录的是该小程序的**管理员微信**
2. 右上角点「**上传**」
3. 填写：
   - **版本号**：`1.0.0`（首次；后续必须递增，微信不允许同版本号重复上传）
   - **项目备注**（建议照抄，方便日后回溯）：
     ```
     v1.0.0 首版：今日/一周页点开看交互、周导航常驻吸顶、Excel 食谱导入
     ```
4. 点「上传」，等待进度条走完，提示「上传成功」

> 备注里写清楚这一版改了什么，mp 后台版本管理里一眼能认出来，别写「更新」「修复问题」这种。

## 二、把上传的版本选为「体验版」

1. 浏览器打开 <https://mp.weixin.qq.com>，用**管理员微信扫码**登录
2. 左侧菜单：**管理 → 版本管理**
3. 在「**开发版本**」里找到刚上传的 `1.0.0`，点右侧「**选为体验版**」
4. 该版本上移到「**体验版本**」区域，说明体验版生效

> 上传后默认是「开发版本」，不点这一步家人扫不到。

## 三、添加体验成员（家人名单）

1. mp 后台：**管理 → 成员管理 → 体验成员** → 点「**添加**」
2. 输入家人的**微信号**（不是昵称，也不是手机号；微信号在微信「我 → 头像 → 微信号」查看）
3. 添加后让对方在微信里**接受邀请**（会收到一条服务通知）
4. 名额有限（一般十几个，以后台页面显示为准），优先加真正会用的家人

> 如果家人找不到微信号，让他用微信扫你 mp 后台的「邀请体验成员」二维码更省事。

---

## 四、把二维码发给家人

1. mp 后台：**管理 → 版本管理 → 体验版本** → 点「**二维码**」
2. 保存小程序码图片，微信直接发给家人
3. 家人用微信**扫一扫**即可打开（不需要下载、不需要开发者权限）

**也可以**：开发者工具里点「预览」生成二维码——但那个二维码 **30 分钟后失效**，适合当场调试，**不适合分发**。分发一律用 mp 后台的体验版二维码（长期有效）。

## 七、常见问题

**Q：家人扫了二维码提示「无权限」？**
A：体验成员没加成功。检查：微信号填对了吗 → 对方接受邀请了吗 → 是不是选成了「开发版本」而不是「体验版本」。

**Q：家人打开是空白页 / 报错？**
A：90% 是云函数没部署。回开发者工具，把 `cloudfunctions/` 下 4 个函数逐个「上传并部署：云端安装依赖」，再让家人重进。仍不行则检查 `miniprogram/config.js` 的 `cloudEnv` 是否为 `cloud1-d1g8yreir12ed382c`。

**Q：家人看到的是空态（没有菜单）？**
A：库里没数据。开发者工具「预览」扫码 → 我的 → 导入 → 选 `docs/food0920.xlsx` → 保存。数据是全局的，家人那边立刻能看到。

**Q：第一次打开很慢？**
A：云函数冷启动正常现象，首次几十秒到 1 分钟属可接受范围；之后会快。若每次都慢，回来查云函数日志。

**Q：体验版和正式版数据是一套吗？**
A：是同一套云环境，体验版改的数据正式发布后依然在。**注意**：家人误操作会真的影响数据（比如覆盖导入食谱），所以分发时别急着让家人自己导入 Excel。

**Q：体验版要不要备案？**
A：不用。ICP 备案是「正式发布/上架」的前置条件，走审核时才需要，详见 `docs/发布操作手册.md` 第四节。

**Q：改了代码想重传？**
A：版本号必须递增（如 `1.0.1`），重新走「上传 → 选为体验版」，家人的二维码不用换，重新扫码或下拉刷新即拿到新版本。
