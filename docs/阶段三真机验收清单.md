## 六、风险关注点

1. **云环境 / 云函数是最大不确定项**：任一函数没部署到位就会出现 FUNCTION_NOT_FOUND，页面应给出友好 envError 而非白屏（G-4）。
2. **周视图吸顶+展开的布局联动**是新改动的核心，重点回归 C-8 / C-9 / H-2。
3. **周期重叠覆盖**是不可逆操作，F-9 必须真机实测，确认提示文案家人能看懂。
4. **tabBar 破图**若真机复现，属于门面问题，应提 P1 阻断。
