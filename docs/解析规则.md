# 好饭 · 解析规则

`cloudfunctions/menuParse/lib/parseExcel.js` 的行为规范。解析器是**零依赖纯函数**：输入 AOA（二维数组），输出结构化食谱 + 告警列表，不碰网络、不碰数据库。

## 1. 目标表格形态

家里实际使用的是「矩阵式周食谱表」：

- 列 = 星期（周日打头，7 列）
- 行 = 餐次（「早」占两行：主食一行、饮品一行）
- A1 是文本日期区间（如 `9/20-9/26`），**没有年份**
- 菜名与配方混写在同一格，分隔符不统一（`：` `:` `；` `;` 换行，甚至没有）
- `/` 表示二选一（如 `酸奶/六物饮`）
- 备料备注按天分布（`食材处理（早）` / `解冻洗净备用（晚）`），另有整周备注（`食材准备` / `备餐`）
- 文件尾部有大量空行空列噪声，表维度虚高（如 200 行 × 26 列）

## 2. 已知的 16 项表格陷阱与对策

| # | 陷阱 | 对策 |
| --- | --- | --- |
| 1 | 表维度虚高 | `scanBounds` 自扫非空格，只认真实边界 |
| 2 | 合并单元格（A 列桩、备注行横跨） | `applyMerges` 按 `!merges` 范围填充（只填空格），并记 W004 |
| 3 | 无合并元数据（纯 AOA 输入） | 行循环里 `lastLabel` 前向填充，空标签但有数据的行继承上一行餐次 |
| 4 | 文本日期无年份 | 候选年 [当前年, +1, -1]，用「起始日星期 == 表头首列星期」校验 |
| 5 | 跨年周（12/28-1/3） | `crossYear` 时结束年 +1，并验证 7 天跨度 |
| 6 | 三年候选都对不上星期 | 回退当前年，`yearAssumed: true` + W002 warn，交给校对页人工切换 |
| 7 | 表头可能不在第一行 | `findHeaderRow` 找含 ≥5 个「周X」的行 |
| 8 | 分隔符不统一 | `splitDish` 按优先级取最早出现者：`：` > `:` > `；` > `;` > `\n` |
| 9 | `/` 二选一 | 拆成 `options[]`，`displayTitle` 用「 或 」连接，记 W007 |
| 10 | 菜名带序号/括号备注/尾部标点 | `normalizeDishKey` 归一化，作为配图映射主键 |
| 11 | 分隔符出现在开头等极端切分 | 整格当菜名并标 `needsReview`（W006） |
| 12 | 超长菜名（整格没写配方） | `displayTitle.length > 20` 或选项 > 16 字 → `needsReview` + W006 |
| 13 | 餐次空格 | 记 `missing: true`，汇总 W005 |
| 14 | 备料行周末缺数据 | 正常缺失，不告警 |
| 15 | 标签无法归类（如「小贴士」） | 保留为 `timing: 'unknown'` 的备料备注，记 W010，不丢弃 |
| 16 | 同周菜名重复 | W009 info，提示可复用配图 |

## 3. 解析流程（十步）

1. `scanBounds` 求真实边界；空表 → `EMPTY` 阻断
2. `findHeaderRow` 找表头与日期列映射；找不到 → `NO_HEADER` 阻断
3. `parseRangeText` 在桩列/表头行找日期区间；找不到 → `NO_RANGE` 阻断
4. `buildPeriod` 年份推断（或采用校对页显式传入的 `year`），生成 7 天骨架
5. 表头星期与推算日期逐列核对，不符 → W003
6. 逐行扫描：桩列取标签 → `classifyRow` 归类为 `meal / prep / global / unknown`
7. `meal` 行：逐天 `splitDish` 切菜名/配方/二选一，早餐按出现顺序自动编 `slot`
8. `prep / unknown` 行：按天落 `prepNotes`（早/晚时序识别），`global` 行落到每天 `globalPrep`
9. 汇总 W005/W006/W007 与重复菜名 W009
10. 输出 `{ ok, period, days, warnings, stats }`

## 4. 告警码

| 码 | 级别 | 含义 |
| --- | --- | --- |
| W001 | error | 表头/区间缺失、空表（阻断性失败，`ok: false`） |
| W002 | info/warn | 年份为推断（info=校验通过命中非当前年；warn=回退当前年） |
| W003 | warn | 表头星期与推算日期不符 / 日期列数 ≠ 7 |
| W004 | info | 检测到合并单元格并已填充 |
| W005 | warn | N 处餐次为空 |
| W006 | warn | 菜名疑似未正确切分（超长/开头分隔符），待校对 |
| W007 | info | `/` 已按二选一处理 |
| W008 | — | 周期重叠（在 menuSave 侧检测，解析器不管） |
| W009 | info | 同周菜名重复，可复用配图 |
| W010 | warn | 行标签无法归类，已按备注保留 |

## 5. 输出数据契约

```js
{
  ok: true,
  period: {
    startDate: '2026-09-20',      // ISO 日期
    endDate: '2026-09-26',
    startWeekday: 0,              // 0=周日
    startWeekdayText: '周日',
    rawRangeText: '9/20-9/26',
    yearAssumed: false,           // true = 年份是猜的，校对页要提示切换
  },
  days: [{
    date: '2026-09-20', weekday: 0, weekdayText: '周日', dayIndex: 0,
    meals: [{
      meal: 'breakfast',          // breakfast | lunch | snack | dinner
      mealText: '早餐',
      slot: 1,                    // 早餐有两行：主食 slot=1、饮品 slot=2
      displayTitle: '莲藕消积米糊',
      options: [],                // 二选一时非空
      recipe: '18g 莲藕，18g苹果',
      rawText: '莲藕消积米糊：18g 莲藕，18g苹果',
      dishKeys: ['莲藕消积米糊'], // normalizeDishKey 归一化，配图主键
      needsReview: false,
      missing: false,
    }],
    prepNotes: [{ label: '食材处理（早）', timing: 'morning', steps: [...], rawText: '...' }],
    globalPrep: { '食材准备': '/排骨/虾' },
  }],
  warnings: [{ code, level, message, detail? }],
  stats: { bounds, headerRow, mealCells, prepNotes, globalPrepRows },
}
```

## 6. 本地验证

```bash
npm test                                       # 19 个用例（复刻真实表格 + 边界）
node scripts/parse-local.js 食谱.xlsx -o out.json   # 对真实文件出 JSON
```

改解析器时先跑 `npm test`；对真实表格有新发现（新的分隔符、新的行标签）时，先把样本补进 `tests/parseExcel.test.js` 的 fixture 再改代码。
